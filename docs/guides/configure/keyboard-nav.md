# 键盘导航

Blockly 通过 `@blockly/keyboard-navigation` 插件提供键盘导航。该插件依赖[焦点系统](/guides/configure/focus)，后续会逐步整合进 Blockly 核心。

你可以通过以下方式获取插件：

- 从 [npm 下载 `@blockly/keyboard-navigation`](https://www.npmjs.com/package/@blockly/keyboard-navigation)
- 从 GitHub 获取 [`blockly-keyboard-experimentation` 仓库](https://github.com/raspberrypifoundation/blockly-keyboard-experimentation/)

如果你想直接体验插件，可访问[无障碍插件演示 playground](https://raspberrypifoundation.github.io/blockly-keyboard-experimentation/)。

## 使用键盘导航

- 点击工作区，或按 `Tab` 直到焦点到达工作区。
- 使用方向键移动。
- 按 `T` 打开工具箱。
- 按 `Enter` 或 `Space` 进行编辑或确认。
- 按 `/` 查看完整快捷键列表。

更多信息可见 [Blockly 无障碍项目页面](https://developers.google.com/blockly/accessibility#projects)。

::: tip 注意
在 Blockly v12 之前存在的键盘导航插件 `0.6` 版本已移除。
:::
