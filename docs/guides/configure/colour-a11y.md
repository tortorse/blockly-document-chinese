# 颜色与无障碍

Blockly 使用颜色来强提示每个块的角色，并将块分组。对于内置块，这个提示通常是辅助信息，块上的文本才是主要信息，因此颜色本身不是关键属性。

但在选择块颜色调色板时，仍应把色盲与色觉缺陷纳入设计考虑。

Blockly 提供了多个[主题](/guides/configure/appearance/themes)，用于兼顾部分色觉缺陷场景。你还可以参考这个[颜色调色板页面](http://mkweb.bcgsc.ca/colorblind/palettes.mhtml#projecthome)，其中提供了 8、12、15、24 色示例，目标是在常见色觉缺陷条件下尽量提升区分度。

需要注意，这些调色板并不等于 Blockly 里刚好使用 8、12、15、24 个块分类，因为还需要预留一部分颜色给阴影块和字段。
