# 工具箱

工具箱是用户获取块的位置，通常显示在工作区的一侧。

[弹出工具箱](/guides/configure/toolboxes/flyout)始终展示同一组块；[分类工具箱](/guides/configure/toolboxes/category)会把块分到不同分类中。

工具箱可以使用 `JSON` 或 `XML` 定义。自 2020 年 9 月版本起支持 `JSON`，并优先推荐使用 `JSON`。

本节主要关注如何定义工具箱结构，也就是有哪些分类，以及每个分类包含哪些块。  
如果你要调整工具箱外观，请参考[分类外观](/guides/configure/toolboxes/appearance)、[自定义 Blockly 工具箱 Codelab](https://blocklycodelabs.dev/codelabs/custom-toolbox/index.html?index=..%2F..index#0)和[2021 Toolbox APIs 演讲](https://www.youtube.com/watch?v=JJVX_YuKDbo&list=PLSIUOFhnxEiCjoIwJ0jAdwpTZET73CK7d&index=9&t=1s)。
