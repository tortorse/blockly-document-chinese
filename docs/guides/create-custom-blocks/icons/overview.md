# 图标

图标用于定义块上的某些界面元素，用来展示或定义块的“元信息”。通常它表现为一个可点击按钮，点击后会打开弹出内容或编辑器。

更多信息见[字段与图标](/guides/create-custom-blocks/fields/fields-vs-icons)。

Blockly 内置了一些常见用途的图标，例如注释和警告。可参考：

- [Icon 类](/reference/js/blockly.icon_class)
- [Comment 类](/reference/js/blockly.comment_class)
- [Warning 类](/reference/js/blockly.warning_class)

如果内置图标不满足你的场景，也可以定义自定义图标。例如，你可以做一个图标，在弹出气泡中显示版本信息或版权信息。

更多信息见[创建自定义图标（总览）](/guides/create-custom-blocks/icons/creating-custom-icons/basic-implementation)。
