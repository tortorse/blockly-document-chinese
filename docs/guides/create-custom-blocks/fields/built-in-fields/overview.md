# 内置字段

Blockly 提供了多种可直接使用的字段，供你在定义块时使用。也有一些字段以[插件](/guides/programming/plugin_overview)形式提供。

内置字段：

- [复选框](/guides/create-custom-blocks/fields/built-in-fields/checkbox)
- [下拉菜单](/guides/create-custom-blocks/fields/built-in-fields/dropdown)
- [图片](/guides/create-custom-blocks/fields/built-in-fields/image)
- [标签](/guides/create-custom-blocks/fields/built-in-fields/label)
- [可序列化标签](/guides/create-custom-blocks/fields/built-in-fields/label-serializable)
- [数字](/guides/create-custom-blocks/fields/built-in-fields/number)
- [文本输入](/guides/create-custom-blocks/fields/built-in-fields/text-input)
- [变量](/guides/create-custom-blocks/fields/built-in-fields/variable)

插件字段：

- [角度选择器](https://www.npmjs.com/package/@blockly/field-angle)
- [位图](https://www.npmjs.com/package/@blockly/field-bitmap)
- [颜色选择器](https://www.npmjs.com/package/@blockly/field-colour)
- [带 HSV 滑块的颜色选择器](https://www.npmjs.com/package/@blockly/field-colour-hsv-sliders)
- [日期](https://www.npmjs.com/package/@blockly/field-date)
- [下拉网格](https://www.npmjs.com/package/@blockly/field-grid-dropdown)
- [依赖下拉菜单](https://www.npmjs.com/package/@blockly/field-dependent-dropdown)
- [多行文本输入](https://www.npmjs.com/package/@blockly/field-multilineinput)
- [数字滑块](https://www.npmjs.com/package/@blockly/field-slider)

完整插件字段列表见 [Blockly Plugins & Demos](https://raspberrypifoundation.github.io/blockly-samples/#fields)。
